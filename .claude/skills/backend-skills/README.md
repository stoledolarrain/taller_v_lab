# Skills de backend Django — Pasanaku Digital

Este paquete contiene 8 carpetas de skills, cada una con un archivo SKILL.md.

## Instalación
Copia las carpetas dentro de la carpeta `skills/` de tu proyecto. La estructura final debe ser:

skills/
  django-backend-architecture/SKILL.md
  django-rest-api/SKILL.md
  django-auth-permissions/SKILL.md
  django-database-modeling/SKILL.md
  pasanaku-business-rules/SKILL.md
  django-transactions-integrity/SKILL.md
  django-testing/SKILL.md
  django-api-security-validation/SKILL.md

## Importante
- Las rutas, modelos y campos de los ejemplos son orientativos.
- Antes de copiar código de ejemplo, adaptarlo al repositorio real.
- El documento del proyecto es la referencia principal de las reglas funcionales.
- Estas skills son instrucciones para orientar el trabajo; no reemplazan la revisión ni la ejecución de pruebas.
