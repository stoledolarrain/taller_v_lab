# Carpeta de Skills y Convenciones de Agentes

Esta carpeta almacena las **Skills**, instrucciones operativas y estándares de arquitectura para el desarrollo asistido por IA de **Pasanaku Digital**.

## Estructura de Skills

- `pasanaku-conventions/`: Define la arquitectura del proyecto (MVVM en React + Service Layer en Django), estándares de código, reglas de negocio críticas del pasanaku y la suite de pruebas requerida.
